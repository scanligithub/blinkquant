## Task 1: P0-1 — 禁止回测路径中的历史板块字段

- Modify: `backend/core/backtest_engine.py`（传入 backtest_mode）

**目标:** 当 `backtest_mode=True` 时，`S_CLOSE`、`S_PCT_CHG`、`INDUSTRY_*`、`SECTOR_*` 字段直接抛 `UnsupportedInBacktestError`。

### 实现要点

1. 在 `engine.py` 新增异常类和 backtest_mode 参数：

```python
class UnsupportedInBacktestError(RuntimeError):
    """回测模式下禁止使用板块/行业字段（PIT leakage 风险）。"""
    pass
```

2. `SelectionEngine.execute_selector()` 和 `_execute_single()` 增加 `backtest_mode=False` 参数。

3. 在 `_execute_single()` 中，当 `backtest_mode=True` 且公式包含 sector 字段时，raise `UnsupportedInBacktestError`。

4. `BacktestEngine.run()` 传入 `backtest_mode=True`。

5. API `/select` 不传 backtest_mode（默认 False），保持实时选股兼容。

### 测试

## Task 2: P0-2 — 修复 frozen_qty 不变量

**Files:**
- Modify: `backend/core/corporate_actions.py`（`adjust_qty_for_split` 返回 frozen_qty）
- Modify: `backend/core/portfolio.py`（`apply_corporate_action` 正确调整 frozen_qty）
- Create: `backend/tests/test_corporate_action_freeze_invariant.py`

**目标:** split/bonus 时正确按比例调整 `available_qty` 和 `frozen_qty`，并验证不变量。

### 实现要点

1. 修改 `adjust_qty_for_split` 签名，增加 `frozen_qty` 参数：

```python
def adjust_qty_for_split(total_qty: int, avg_cost: float,
                         split_ratio: float,
                         frozen_qty: int = 0) -> tuple[int, float, int, int]:
    """返回 (new_total, new_cost, new_available, new_frozen)"""
    if split_ratio <= 0 or split_ratio == 1.0:
        return total_qty, avg_cost, total_qty - frozen_qty, frozen_qty
    new_total = int(total_qty * split_ratio)
    new_frozen = int(frozen_qty * split_ratio)
    new_available = new_total - new_frozen
    new_cost = avg_cost / split_ratio if split_ratio > 0 else 0.0
    return new_total, new_cost, new_available, new_frozen
```

2. 修改 `Portfolio.apply_corporate_action` 使用新的返回值：

```python
elif action.action_type in (ActionType.STOCK_SPLIT, ActionType.BONUS_SHARES):
    new_total, new_cost, new_avail, new_frozen = adjust_qty_for_split(
        pos.total_qty, pos.avg_cost, action.split_ratio, pos.frozen_qty)
    pos.total_qty = new_total
    pos.avg_cost = new_cost
    pos.available_qty = new_avail
    pos.frozen_qty = new_frozen
    # 验证不变量
    assert pos.available_qty + pos.frozen_qty == pos.total_qty
```

### 测试

```python
def test_split_with_frozen_qty():
    """T+1 冻结的股份在拆股后正确按比例调整。"""
    p = Portfolio(initial_cash=100000.0)
    p.positions["000001"] = Position(
        code="000001", total_qty=1000, available_qty=900,
        frozen_qty=100, avg_cost=20.0, market_value=0.0)
    p.apply_corporate_action(CorporateAction(
        date=datetime.date(2024, 12, 25), code="000001",
        action_type=ActionType.STOCK_SPLIT, split_ratio=2.0))
    assert p.positions["000001"].total_qty == 2000
    assert p.positions["000001"].available_qty == 1800
    assert p.positions["000001"].frozen_qty == 200
    assert p.positions["000001"].available_qty + p.positions["000001"].frozen_qty == p.positions["000001"].total_qty

def test_bonus_with_odd_frozen():
    """10送3（1.3x），frozen 不能整除时向下取整。"""
    p = Portfolio(initial_cash=100000.0)
    p.positions["000001"] = Position(
        code="000001", total_qty=1000, available_qty=950,
        frozen_qty=50, avg_cost=20.0, market_value=0.0)
    p.apply_corporate_action(CorporateAction(
        date=datetime.date(2024, 9, 15), code="000001",
        action_type=ActionType.BONUS_SHARES, split_ratio=1.3))
    assert p.positions["000001"].available_qty + p.positions["000001"].frozen_qty == p.positions["000001"].total_qty
```
