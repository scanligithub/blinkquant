**Goal:** Create a deterministic golden regression test for 2024Q1 full-market backtest that serves as the v1.0 release gate — proving the engine produces correct results on real market data.

**Architecture:** Generate golden artifacts from a fixed deterministic strategy on real 2024Q1 data, then assert exact match on subsequent runs. The strategy is intentionally simple (MA20 crossover on CSI300, weekly rebalance, top-20 equal weight) to isolate engine correctness from Alpha complexity.

**Tech Stack:** Polars, pytest, HuggingFace Hub (hf_hub_download), YAML fee config, existing BacktestEngine pipeline

---

## Design Decisions

### Strategy Specification
- **Universe:** CSI300 constituent codes (filtered from full market)
- **Signal:** `CLOSE > MA(CLOSE, 20)` — above 20-day moving average
- **Rebalance:** Weekly (last trading day of each week)
- **Position sizing:** Top 20 codes by code ascending, equal weight
- **Initial cash:** 10,000,000 CNY
- **Fee schedule:** Historical (post-2023-08-28 rates from `config/fee_schedule.yaml`)

### Why This Strategy
1. **Deterministic:** No random elements, no ranking ambiguity
2. **Simple:** MA20 is built into the registry, no custom code needed
3. **Covers edge cases:** Weekly rebalance means T+1 freeze crosses week boundaries; 20 stocks means cash constraints likely trigger partial fills
4. **Repeatable:** Same inputs → same outputs, guaranteed by Event State Machine

### Artifact Format
```
tests/golden/2024q1/
├── equity_curve.parquet      # date, equity, cash, positions_value, signal_date
├── trades.parquet            # signal_date, execution_date, code, side, qty, price, fee
├── positions_daily.parquet   # date, code, qty, cost, market_value
├── metrics.json              # total_return, cagr, sharpe, max_drawdown, total_days
├── diagnostics.json          # execution_diagnostics dict
└── metadata.json             # strategy params, data version, generation timestamp
```

### Regression Mechanism
- `test_golden_2024q1.py` loads golden artifacts and compares against a fresh run
- Float tolerance: 1e-6 for equity/positions, 1e-9 for fees
- Trades compared by (execution_date, code, side) key
- `generate_golden.py` script regenerates artifacts when strategy changes

```python
"""Generate golden artifacts for 2024Q1 backtest regression test.

Usage:
    cd backend
    python scripts/generate_golden.py

Requires:
    - HF_TOKEN environment variable (for HF data access)
    - HF_ENDPOINT=https://hf-mirror.com (if in China)

Output:
    tests/golden/2024q1/*.parquet, *.json
"""
import datetime
import json
import os
import sys
from pathlib import Path

import polars as pl

# Add parent dir to path for imports
sys.path.insert(0, str(Path(__file__).parent.parent))

from core.backtest_engine import BacktestEngine, TradingCalendar
from core.raw_price_store import RawPriceStore
from core.portfolio import Position
from core.backtest_types import (
    FeeConfig, FeeSchedule, ExecutionConfig, MVP_EXECUTION_CONFIG,
    top_n_equal_weight_allocator,
)
from core.fee_config import load_fee_schedule
from core.data_manager import data_manager
from core.engine import selection_engine

GOLDEN_DIR = Path(__file__).parent.parent.parent / "tests" / "golden" / "2024q1"
HF_REPO = "scanli/stocka-data"


def load_trade_dates_from_hf(hf_repo: str, token: str) -> list[datetime.date]:
    """Load trading calendar from HF dataset."""
    from huggingface_hub import hf_hub_download
    path = hf_hub_download(
        repo_id=hf_repo,
        filename="trading_dates.parquet",
        repo_type="dataset",
        token=token,
    )
    df = pl.read_parquet(path)
    dates = df["date"].cast(pl.Date).to_list()
    return sorted(dates)


def load_csi300_codes_from_hf(hf_repo: str, token: str) -> list[str]:
    """Load CSI300 constituent codes from HF dataset.
    
    Falls back to all codes in stock_basic.parquet if CSI300 specific
    file is not available.
    """
    from huggingface_hub import hf_hub_download
    try:
        path = hf_hub_download(
            repo_id=hf_repo,
            filename="stock_basic.parquet",
            repo_type="dataset",
            token=token,
        )
        df = pl.read_parquet(path)
        codes = df["code"].to_list()
        return sorted(codes)
    except Exception as e:
        print(f"Warning: Could not load stock_basic: {e}")
        return []


def run_golden_backtest(
    trade_dates: list[datetime.date],
    all_codes: list[str],
    hf_repo: str,
    token: str,
) -> dict:
    """Run the golden backtest and return results."""
    start_date = datetime.date(2024, 1, 2)
    end_signal_date = datetime.date(2024, 3, 29)

    # Calendar: must include at least one day after end_signal_date for T+1
    cal = TradingCalendar()
    cal.set_trade_dates(trade_dates)

    # Fee schedule
    fee_schedule_path = Path(__file__).parent.parent.parent / "config" / "fee_schedule.yaml"
    fee_schedule = load_fee_schedule(fee_schedule_path)

    # Raw price store (HF backend)
    raw_store = RawPriceStore(hf_repo_id=hf_repo, hf_token=token)

    # Install data into data_manager for selection engine
    # Load the full quarter into df_daily
    lf = raw_store.scan_window(start_date, end_signal_date)
    df_daily = lf.collect()
    data_manager.df_daily = df_daily
    data_manager.df_mapping = None
    data_manager._asof_frame_cache.clear()
    data_manager._resample_all()
    selection_engine._set_cache.clear()

    # Allocator: top 20 equal weight, deterministic code asc
    allocator = top_n_equal_weight_allocator(20)

    # Build engine
    engine = BacktestEngine(
        calendar=cal,
        selection_engine=selection_engine,
        raw_price_store=raw_store,
        fee_config=FeeConfig(),
        execution_config=MVP_EXECUTION_CONFIG,
        allocator=allocator,
    )

    # Run
    result = engine.run(
        formula="CLOSE > MA(CLOSE, 20)",
        start_date=start_date,
        end_signal_date=end_signal_date,
        initial_cash=10_000_000,
        rebalance_freq="weekly",
    )

    return {
        "equity_curve": result.equity_curve,
        "trades": result.trades,
        "positions_daily": result.positions_daily,
        "metrics": result.metrics,
        "diagnostics": result.execution_diagnostics,
    }


def save_golden_artifacts(results: dict):
    """Save results to golden artifact directory."""
    GOLDEN_DIR.mkdir(parents=True, exist_ok=True)

    results["equity_curve"].write_parquet(GOLDEN_DIR / "equity_curve.parquet")
    results["trades"].write_parquet(GOLDEN_DIR / "trades.parquet")
    results["positions_daily"].write_parquet(GOLDEN_DIR / "positions_daily.parquet")

    with open(GOLDEN_DIR / "metrics.json", "w") as f:
        json.dump(results["metrics"], f, indent=2, default=str)

    with open(GOLDEN_DIR / "diagnostics.json", "w") as f:
        json.dump(results["diagnostics"], f, indent=2, default=str)

    # Update metadata
    metadata_path = GOLDEN_DIR / "metadata.json"
    with open(metadata_path) as f:
        metadata = json.load(f)
    metadata["generated_at"] = datetime.datetime.now().isoformat()
    with open(metadata_path, "w") as f:
        json.dump(metadata, f, indent=2)

    print(f"Golden artifacts saved to {GOLDEN_DIR}")
    print(f"  equity_curve: {results['equity_curve'].height} rows")
    print(f"  trades: {results['trades'].height} rows")
    print(f"  positions_daily: {results['positions_daily'].height} rows")
    print(f"  metrics: {json.dumps(results['metrics'], indent=2)}")


def main():
    token = os.getenv("HF_TOKEN")
    if not token:
        print("Error: HF_TOKEN not set")
        sys.exit(1)

    hf_repo = os.getenv("HF_REPO", HF_REPO)

    print(f"Loading trade dates from {hf_repo}...")
    trade_dates = load_trade_dates_from_hf(hf_repo, token)
    print(f"  {len(trade_dates)} trade dates loaded")

    print(f"Loading stock codes...")
    all_codes = load_csi300_codes_from_hf(hf_repo, token)
    print(f"  {len(all_codes)} codes loaded")

    print("Running golden backtest...")
    results = run_golden_backtest(trade_dates, all_codes, hf_repo, token)

    print("Saving golden artifacts...")
    save_golden_artifacts(results)

    # Cleanup
    data_manager.df_daily = None
    data_manager.df_weekly = None
    data_manager.df_monthly = None
    data_manager._asof_frame_cache.clear()

    print("Done!")


if __name__ == "__main__":
    main()
```

"""Golden regression test for 2024Q1 backtest.

Compares a fresh backtest run against stored golden artifacts.
This is the v1.0 release gate — all assertions must pass.

Strategy:
  - Formula: CLOSE > MA(CLOSE, 20)
  - Rebalance: weekly
  - Top N: 20, equal weight
  - Initial cash: 10,000,000
  - Fee schedule: historical (post-2023-08-28)
"""
import datetime
import json
from pathlib import Path

import polars as pl
import pytest

from core.backtest_engine import BacktestEngine, TradingCalendar
from core.raw_price_store import RawPriceStore
from core.portfolio import Position
from core.backtest_types import (
    FeeConfig, FeeSchedule, MVP_EXECUTION_CONFIG,
    top_n_equal_weight_allocator,
)
from core.fee_config import load_fee_schedule
from core.data_manager import data_manager
from core.engine import selection_engine

GOLDEN_DIR = Path(__file__).parent.parent.parent / "tests" / "golden" / "2024q1"
HF_REPO = "scanli/stocka-data"


def _load_golden(name: str):
    """Load a golden artifact file."""
    path = GOLDEN_DIR / name
    if not path.exists():
        pytest.skip(f"Golden artifact not found: {path}")
    if name.endswith(".parquet"):
        return pl.read_parquet(path)
    elif name.endswith(".json"):
        with open(path) as f:
            return json.load(f)
    return None


def _assert_equity_curve_eq(actual: pl.DataFrame, expected: pl.DataFrame, tol: float = 1e-6):
    """Assert equity curves match within tolerance."""
    assert actual.height == expected.height, \
        f"Row count: {actual.height} != {expected.height}"

    actual_sorted = actual.sort("date").to_dicts()
    expected_sorted = expected.sort("date").to_dicts()

    for a, e in zip(actual_sorted, expected_sorted):
        assert a["date"] == e["date"], f"Date mismatch: {a['date']} != {e['date']}"
        for col in ["equity", "cash", "positions_value"]:
            assert abs(a[col] - e[col]) <= tol, \
                f"{col} on {a['date']}: {a[col]} != {e[col]} (diff={abs(a[col]-e[col])})"


def _assert_trades_eq(actual: pl.DataFrame, expected: pl.DataFrame, tol: float = 1e-6):
    """Assert trades match exactly."""
    if expected.height == 0 and actual.height == 0:
        return
    assert actual.height == expected.height, \
        f"Trade count: {actual.height} != {expected.height}"

    key_cols = ["execution_date", "code", "side"]
    actual_sorted = actual.sort(key_cols).to_dicts()
    expected_sorted = expected.sort(key_cols).to_dicts()

    for a, e in zip(actual_sorted, expected_sorted):
        for col in key_cols:
            assert a[col] == e[col], f"Trade key mismatch: {a[col]} != {e[col]}"
        assert a["qty"] == e["qty"], \
            f"Qty on {a['execution_date']} {a['code']}: {a['qty']} != {e['qty']}"
        assert abs(a["price"] - e["price"]) <= tol, \
            f"Price on {a['execution_date']} {a['code']}: {a['price']} != {e['price']}"
        assert abs(a["fee"] - e["fee"]) <= 0.01, \
            f"Fee on {a['execution_date']} {a['code']}: {a['fee']} != {e['fee']}"


def _assert_positions_eq(actual: pl.DataFrame, expected: pl.DataFrame, tol: float = 1e-6):
    """Assert positions_daily match."""
    if expected.height == 0 and actual.height == 0:
        return
    assert actual.height == expected.height, \
        f"Position rows: {actual.height} != {expected.height}"

    key_cols = ["date", "code"]
    actual_sorted = actual.sort(key_cols).to_dicts()
    expected_sorted = expected.sort(key_cols).to_dicts()

    for a, e in zip(actual_sorted, expected_sorted):
        for col in key_cols:
            assert a[col] == e[col], f"Position key mismatch: {a[col]} != {e[col]}"
        assert a["qty"] == e["qty"], \
            f"Qty on {a['date']} {a['code']}: {a['qty']} != {e['qty']}"
        assert abs(a["cost"] - e["cost"]) <= tol, \
            f"Cost on {a['date']} {a['code']}: {a['cost']} != {e['cost']}"


def _assert_metrics_eq(actual: dict, expected: dict, tol: float = 1e-6):
    """Assert metrics match."""
    for key in expected:
        if key not in actual:
            pytest.fail(f"Missing metric: {key}")
        if isinstance(expected[key], (int, float)):
            assert abs(actual[key] - expected[key]) <= tol, \
                f"Metric {key}: {actual[key]} != {expected[key]}"

class TestGoldenEquityCurve:
    """Golden equity curve regression."""

    def test_equity_curve_row_count(self):
        golden = _load_golden("equity_curve.parquet")
        # 2024Q1 has ~57 trading days
        assert golden.height >= 50, f"Expected >=50 rows, got {golden.height}"

    def test_equity_curve_dates_monotonic(self):
        golden = _load_golden("equity_curve.parquet")
        dates = golden["date"].to_list()
        assert dates == sorted(dates), "Dates not monotonic"

    def test_equity_curve_first_row(self):
        golden = _load_golden("equity_curve.parquet")
        first = golden.head(1).to_dicts()[0]
        # First day: cash = initial_cash, positions_value = 0
        assert abs(first["cash"] - 10_000_000) < 1e-6
        assert first["positions_value"] == 0

    def test_equity_curve_cash_never_negative(self):
        golden = _load_golden("equity_curve.parquet")
        cash_vals = golden["cash"].to_list()
        assert all(c >= -1e-6 for c in cash_vals), "Cash went negative"


class TestGoldenTrades:
    """Golden trades regression."""

    def test_trades_have_all_columns(self):
        golden = _load_golden("trades.parquet")
        expected_cols = {"signal_date", "execution_date", "code", "side", "qty", "price", "fee"}
        assert expected_cols.issubset(set(golden.columns))

    def test_trades_t1_ordering(self):
        """All trades: execution_date > signal_date (T+1)."""
        golden = _load_golden("trades.parquet")
        if golden.height == 0:
            pytest.skip("No trades in golden")
        for row in golden.iter_rows(named=True):
            assert row["execution_date"] > row["signal_date"], \
                f"T+1 violation: exec={row['execution_date']} <= sig={row['signal_date']}"

    def test_trades_lot_size_compliance(self):
        """BUY trades: qty % 100 == 0."""
        golden = _load_golden("trades.parquet")
        buys = golden.filter(pl.col("side") == "BUY")
        for row in buys.iter_rows(named=True):
            assert row["qty"] % 100 == 0, \
                f"BUY lot size violation: {row['code']} qty={row['qty']}"

    def test_trades_positive_fee(self):
        golden = _load_golden("trades.parquet")
        for row in golden.iter_rows(named=True):
            assert row["fee"] >= 0, f"Negative fee: {row['fee']}"


class TestGoldenPositions:
    """Golden positions regression."""

    def test_positions_have_all_columns(self):

        expected_cols = {"date", "code", "qty", "cost", "market_value"}

    def test_positions_qty_positive(self):

    """Golden metrics regression."""

    def test_metrics_have_required_keys(self):
        golden = _load_golden("metrics.json")
        required = {"total_return", "cagr", "sharpe", "max_drawdown", "total_days"}
        assert required.issubset(set(golden.keys()))

    def test_metrics_total_days(self):
        golden = _load_golden("metrics.json")
        assert golden["total_days"] >= 50


class TestGoldenDiagnostics:
    """Golden diagnostics regression."""

    def test_diagnostics_have_required_keys(self):
        golden = _load_golden("diagnostics.json")
        required = {"rej_counters", "intents_total", "partial_fill_count", "carried_events"}
        assert required.issubset(set(golden.keys()))

    def test_no_invariant_violations(self):
        golden = _load_golden("diagnostics.json")
        assert golden.get("negative_cash_count", 0) == 0
        assert golden.get("accounting_invariant_violations", 0) == 0


class TestGoldenDeterminism:
    """Verify golden artifacts are deterministic (same run produces same results)."""

    def test_equity_curve_deterministic(self):
        """Load golden, re-run backtest, compare equity curves."""
        golden_ec = _load_golden("equity_curve.parquet")
        golden_meta = _load_golden("metadata.json")

        # This test only runs if HF_TOKEN is available
        token = __import__("os").getenv("HF_TOKEN")
        if not token:
            pytest.skip("HF_TOKEN not set")

        # Re-run the same backtest
        from huggingface_hub import hf_hub_download
        import os

        hf_repo = golden_meta["data"]["hf_repo"]

        # Load trade dates
        td_path = hf_hub_download(repo_id=hf_repo, filename="trading_dates.parquet",
                                  repo_type="dataset", token=token)

        # Build calendar
        cal = TradingCalendar()
        cal.set_trade_dates(trade_dates)

        # Build raw store
        raw_store = RawPriceStore(hf_repo_id=hf_repo, hf_token=token)

        # Load data into data_manager
        start = datetime.date(2024, 1, 2)
        end = datetime.date(2024, 3, 29)
        lf = raw_store.scan_window(start, end)
        data_manager.df_daily = lf.collect()
        data_manager.df_mapping = None
        data_manager._asof_frame_cache.clear()
        data_manager._resample_all()
        selection_engine._set_cache.clear()

        # Fee schedule
        fee_schedule_path = Path(__file__).parent.parent.parent / "config" / "fee_schedule.yaml"
        fee_schedule = load_fee_schedule(fee_schedule_path)

        # Engine
        engine = BacktestEngine(
            calendar=cal,
            selection_engine=selection_engine,
            raw_price_store=raw_store,
            fee_config=FeeConfig(),
            execution_config=MVP_EXECUTION_CONFIG,
            allocator=top_n_equal_weight_allocator(20),
        )

        result = engine.run(
            formula=golden_meta["strategy"]["formula"],
            start_date=start,
            end_signal_date=end,
            initial_cash=golden_meta["strategy"]["initial_cash"],
            rebalance_freq=golden_meta["strategy"]["rebalance_freq"],
            fee_schedule=fee_schedule,
        )

        # Compare
        _assert_equity_curve_eq(result.equity_curve, golden_ec)

        # Cleanup

        data_manager.df_weekly = None
        data_manager.df_monthly = None
        data_manager._asof_frame_cache.clear()

## Notes

### If HF Data Is Unavailable
The golden tests will `pytest.skip` if artifacts don't exist. This is by design — the golden case requires real market data that can't be committed to git (too large).

### When Strategy Changes
1. Update strategy params in `metadata.json`
2. Run `generate_golden.py` to regenerate artifacts
3. Run `test_golden_2024q1.py` to verify
4. Commit the new artifacts

### Artifact Size
- equity_curve.parquet: ~5 KB (57 rows × 5 cols)
- trades.parquet: ~50 KB (estimated 200-500 trades)
- positions_daily.parquet: ~100 KB (estimated 1000-2000 rows)
- Total: ~200 KB — small enough to commit to git
