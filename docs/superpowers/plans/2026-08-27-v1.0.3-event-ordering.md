# Backtest Engine v1.0.3 Event Ordering Hardening Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修复同一天“signal 与 execution 交叉”时的事件顺序，保证目标组合基于执行后的真实持仓计算。

**Core Issue:** 当前 `BacktestEngine.run()` 在每个交易日 `t` 的顺序是：
```
1. 生成 t 的新 signal（基于未执行 t-1 订单的 stale portfolio）
2. 执行 t-1 的 pending orders
```
正确顺序应为：
```
1. 执行 t-1 的 pending orders（基于 t-1 signal）
2. 生成 t 的新 signal（基于已执行 t-1 订单的真实 portfolio）
```

**Architecture:** 增量重排 event loop，不改变已有接口/契约。

## Task 1: P0-1 — Event Loop 重排：execution 先于 signal

**Files:**
- Modify: `backend/core/backtest_engine.py`（`run()` event loop）
- Create: `backend/tests/test_event_ordering.py`

**目标:** 每个交易日 `t` 先执行到期订单，再生成新信号。

### 实现要点

当前 event loop 结构（简化）：

```python
for t in all_days:
    # 0. Daily thaw / corporate actions
    self.portfolio.daily_thaw()
    if corporate_action_store:
        ...
    
    # 1. Selection scheduling (生成新信号) ← 错误：在 execution 前
    if t in allowed_signals:
        sel = self.selection_engine.execute_selector(...)
        weights = self.allocator(sel.codes, t)
        self._pend_intents = self._generate_intents(weights, new_prices)
        self._pend_sig, self._pend_exec = t, exec_d
    
    # 2. 执行上一信号日的到期意图 ← 错误：在 signal 后
    if self._pend_sig is not None and t == self._pend_exec:
        report = self.execution_engine.execute(...)
        self.portfolio.apply_fills(...)
```

正确顺序：

```python
for t in all_days:
    # 0. Daily thaw / corporate actions
    self.portfolio.daily_thaw()
    if corporate_action_store:
        ...
    
    # 1. 执行到期的 pending orders（来自 t-1 的 signal）
    if self._pend_sig is not None and t == self._pend_exec:
        report = self.execution_engine.execute(...)
        self.portfolio.apply_fills(...)
        # 清理 pending
        self._pend_intents = []
        self._pend_sig = None
        self._pend_exec = None
    
    # 2. Selection scheduling（生成 t 的新 signal，execution 是 t+1）
    if t in allowed_signals:
        sel = self.selection_engine.execute_selector(...)
        weights = self.allocator(sel.codes, t)
        self._pend_intents = self._generate_intents(weights, new_prices)
        self._pend_sig, self._pend_exec = t, exec_d
```

**关键点：** 
- `_pend_sig` 存储的是 signal_date（信号生成日）
- `_pend_exec` 存储的是 execution_date（执行日）
- 执行完毕后清理 pending state
