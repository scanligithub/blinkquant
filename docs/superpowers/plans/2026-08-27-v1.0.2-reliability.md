## Task 1: P0-1 — Selection error 在 backtest 中 fail-fast

**Files:**
- Modify: `backend/core/engine.py`（新增 `BacktestSelectionError`）
- Modify: `backend/core/backtest_engine.py`（catch error → raise）
- Create: `backend/tests/test_selection_failure_abort.py`

**目标:** 回测模式下，SelectionEngine 返回 `{"error": ...}` 时，BacktestEngine 立即抛异常，不继续运行。

### 实现要点

1. 在 `engine.py` 新增异常类：

```python
class BacktestSelectionError(RuntimeError):
    """回测模式下选股失败，立即中止回测。"""
    pass
```

2. 修改 `BacktestEngine.run()` 中两处 selection 调用（ranking path 和 non-ranking path）：

```python
# 修改前：
sel = self.selection_engine.execute_selector(...)
if not (isinstance(sel, dict) and "error" in sel):
    ...

# 修改后：
sel = self.selection_engine.execute_selector(...)
if isinstance(sel, dict) and "error" in sel:
    raise BacktestSelectionError(
        f"Signal date {t}: selection failed: {sel['error']}")
codes = sel.codes
```

3. 实时选股（API `/select`）保持原有 `{"error": ...}` 行为不变。

## Task 2: P0-2 — MTF atom error 在 backtest 中 fail-fast

**Files:**
- Modify: `backend/core/engine.py`（`_eval_atom` 异常处理）
- Create: `backend/tests/test_selection_failure_abort.py`（追加 MTF 测试）

**目标:** MTF atom 计算异常时，立即抛异常而不是返回空集合。

### 实现要点

1. 修改 `_eval_atom()` 中的异常处理：

```python
# 修改前：
except Exception as e:
    logger.warning(f"Atom eval failed for {tf}: {e}")
    result_codes = set()

# 修改后：
except Exception as e:
    raise BacktestSelectionError(
        f"MTF atom evaluation failed: tf={tf}, "
        f"target_date={target_date}, atom={atom.get('source', '?')}: {e}"
    ) from e
```

2. `_execute_single()` 中的异常处理也应改为 raise（而非返回 error dict）：

```python
# 修改前：
except Exception as e:
    return {"error": str(e)}

# 修改后：
except Exception as e:
    raise BacktestSelectionError(
        f"Selection failed for formula={formula!r}, "
        f"target_date={target_date}: {e}"
    ) from e
```

3. 注意：`execute_selector()` 本身的 try/except 保留（用于实时选股兼容），但 `_execute_single` 和 `_eval_atom` 应直接 raise。

## Task 3: P1-1 — FeeSchedule 空 entries fail-fast

**Files:**
- Modify: `backend/core/backtest_types.py`（`FeeSchedule.__post_init__`）
- Create: `backend/tests/test_fee_schedule_edge.py`

**目标:** `FeeSchedule(entries=[])` 在构造时抛异常，不在运行时 IndexError。

### 实现要点

```python
@dataclass
class FeeSchedule:
    entries: list

    def __post_init__(self):
        if not self.entries:
            raise ValueError("FeeSchedule requires at least one entry")
        self.entries = sorted(self.entries, key=lambda e: e.date_start or datetime.date.min)
```

### 测试

```python
def test_empty_fee_schedule_rejected():
    with pytest.raises(ValueError, match="requires at least one entry"):
        FeeSchedule(entries=[])

def test_single_entry_fee_schedule():
    schedule = FeeSchedule(entries=[FeeConfig()])
    assert len(schedule.entries) == 1
```
