# BlinkQuant IA v2：IA3.1 任务中心

状态：实现中，首版代码已提交

## 目标

把“任务执行发生了什么”从选股/回测工作台中独立出来，形成稳定的 `/tasks` 与 `/tasks/[taskId]` 入口。

## 本阶段完成

- `/tasks`：统一查看当前用户的选股、回测任务。
- 支持按任务类型筛选。
- 支持按状态筛选。
- 展示运行状态、节点、时间、进度、回测摘要、策略版本绑定与错误。
- 支持取消可取消任务。
- 支持对终态回测任务重跑，并跳转新任务详情。
- `/tasks/[taskId]`：展示任务执行信息、进度、策略版本绑定、错误、结果摘要和任务输入快照。
- 任务详情继续通过现有 `/api/v1/tasks` API 获取，不新增调度逻辑。
- 一级导航“任务中心”启用。

## 边界

任务中心只负责任务查询与用户允许的任务操作，不承担 Scheduler 职责，不直接控制 Node1/2/3。

成果库仍作为下一阶段对象，任务详情暂不把大型 Artifact 数据直接嵌入页面。

## 验收标准

- `/tasks` 登录态正确。
- 用户只能看到自己的任务；管理员行为继续由现有 API 权限控制。
- 任务轮询不影响调度。
- `/tasks/[taskId]` 刷新和直接访问可用。
- 选股优先、回测并发、抢占等现有调度语义不改变。
