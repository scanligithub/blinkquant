# BlinkQuant IA v2：IA3.4 系统状态页

状态：实现中

## 目标

将集群运行健康和队列诊断从选股工作台独立到 `/system`，为普通用户提供只读运行视图。

## 数据与边界

- 复用已认证的 `GET /api/v1/cluster/status`，数据仍由 Node1 Scheduler 汇总。
- 展示节点状态、当前任务、心跳、generation、最近错误，以及选股/回测待处理队列和运行任务。
- 自动刷新间隔 10 秒，提供手动刷新与读取错误提示。
- 任务条目链接到现有 `/tasks/[taskId]`。
- 页面只读；不增加节点启停/调度控制，不修改 Scheduler、任务 API 或计算内核。
- 未登录用户重定向到 `/login`。

## 验收标准

- `/system` 路由可直接访问和刷新。
- 主导航“系统状态”启用并能正确高亮。
- API 失败时显示可理解的错误，不伪报节点健康。
- 节点和队列数据显示与状态 API 一致。
- 不新增高频轮询；自动刷新每 10 秒。
