## 1. 背景与核心目标

### 1.1 驱动因素
上游 `stockA` 流水线产出格式发生结构性变更，BlinkQuant 后端与前端需同步适配：
- 文件命名从「节点分片」改为「年份分片」
- 股票 code 从纯数字升级为带市场前缀标准码
- 复权因子从「前复权因子」变为「后复权因子」（累乘正序）
- 新增板块成分股映射文件与基本面/事件宽表字段
- 板块 JSON 元数据引入三维分类（行业/概念/地域）

### 1.2 核心约束（不可妥协）
- **分布式分片必须保留**：`code.hash() % 3` 不可移除，单节点内存需控制在 2~3GB
- **选股引擎与前端图表统一使用前复权（QFQ）**：技术分析标准，策略可解释性
- **板块 Join 退化 1-to-1**：行业板块唯一绑定，消除 1-to-N 膨胀风险

#### 3.1.2 df_mapping 构建逻辑（行业优先 1-to-1）
```python
def _load_sector_mapping(self, bio):
    """
    加载 sector_constituents，关联 sector_list 获取 type
    规则：优先行业板块，兜底概念板块，强制 1-to-1
    """
    constituents = pl.read_parquet(bio)  # sector_code, stock_code, sector_name, date
    sectors = pl.read_parquet(bio_sector_list)  # code, name, type
    
    # Inner Join 获取 type
    mapped = constituents.join(sectors, left_on="sector_code", right_on="code", how="inner")
    
    # 过滤行业板块
    industry = mapped.filter(pl.col("type") == "行业板块")
    
    # 兜底：无行业板块的股票，取第一个概念板块
    if industry.is_empty():
        industry = mapped.filter(pl.col("type") == "概念板块")
    
    # stock_code 补全前缀
    industry = industry.with_columns(
        pl.when(pl.col("stock_code").str.starts_with("6"))
          .then(pl.lit("sh.") + pl.col("stock_code"))
          .when(pl.col("stock_code").str.starts_with("0") | pl.col("stock_code").str.starts_with("3"))
          .then(pl.lit("sz.") + pl.col("stock_code"))
          .when(pl.col("stock_code").str.starts_with("4") | pl.col("stock_code").str.starts_with("8") | pl.col("stock_code").str.starts_with("9"))
          .then(pl.lit("bj.") + pl.col("stock_code"))
          .otherwise(pl.col("stock_code"))
          .alias("code")  # 覆盖为带前缀 code，方便后续 Join
    )
    
    # 强制 1-to-1：每个 stock_code 只保留一行
    self.df_mapping = industry.unique(subset=["code"], keep="first").select([
        pl.col("code"), pl.col("sector_code"), pl.col("name").alias("sector_name")
    ])
```

#### 3.1.4 内存优化扩展
新增字段中的大整数字段（`total_shares`, `float_shares`, `total_mv`, `float_mv`）必须保留 `Float64`，其余 Float64 行情字段可降级为 Float32。

```python
def _optimize_memory(self, df, name):
    """将非大整数 Float64 降级为 Float32，降低 50% 内存消耗"""
    if df is None:
        return
    # 必须保留 Float64 的字段（大整数/高精度需求）
    keep_f64 = {"volume", "amount", "total_shares", "float_shares", "total_mv", "float_mv", "forecast_yoy"}
    f64_cols = [c for c, t in df.schema.items() if t == pl.Float64 and c not in keep_f64]
    if f64_cols:
        opt = df.with_columns([pl.col(c).cast(pl.Float32) for c in f64_cols])
        setattr(self, name, opt)
```

```typescript
export function cleanSearchInput(text: string): string {
  if (!text) return '';
  let cleaned = text.replace(/[\s\u3000]/g, '');
  cleaned = cleaned.replace(/[‘’“”、，。,.!！?？;；:：\-—_—\[\]{}()<>【】《》]/g, '');
  // 保留 sh./sz./bj. 前缀，转为小写
  return cleaned.toLowerCase();
}
```

### P2-2 | `frontend/src/utils/pinyin.ts` | 兼容带前缀拼音搜索

```typescript
export function getPinyinInitials(text: string): string {
  if (!text) return '';
  // 分离前缀与中文名：sh.600000 或 平安
  const parts = text.split('.');
  let target = text;
  if (parts.length === 2 && (parts[0] === 'sh' || parts[0] === 'sz' || parts[0] === 'bj')) {
    target = parts[1];  // 纯数字无拼音，返回空即可
  }
  const hasChinese = /[\u4e00-\u9fff]/.test(target);
  if (!hasChinese) return text.toLowerCase();
  
  const initials = pinyin(target, { pattern: 'first', toneType: 'none', type: 'array' })
    .join('').toLowerCase();
  return initials.replace(/[^a-z]/g, '');
}
```

## 5. 风险评估与回退方案

| 风险点 | 概率 | 影响 | 缓解措施 | 回退方案 |
|--------|------|------|----------|----------|
| 新 code 格式导致搜索匹配失败 | 中 | 用户无法搜到股票 | 清洁输入 + 拼音兼容带前缀 | 回退旧版 `cleanInput` |
| sector_constituents 加载失败 | 低 | 板块 Join 降级为跳过 | `try/except` 防御 + 日志告警 | `df_mapping=None` 旧行为 |
| 前复权公式在新因子下边界错误 | 低 | 极端行情价格异常 | `adjustFactor` 熔断校验（0.2~5.0） | 截断到 [0.5, 2.0] 安全区间 |
| 新字段导致 Parquet schema 不兼容 | 低 | API 500 错误 | `target_cols` 用 `if col in df.columns` 动态过滤 | 保持旧 target_cols 白名单 |
